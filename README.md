Made with Claude AI.

It uses **Dataview**, **JS Engine** and **Meta Bind** plugins with Bases obsidian plugin. In Meta Bind setup to enable Javascript if you havent already.

How to Install:
1. Place the css files in you Vault folder in .obsidian -> snippets
2. Place the character-sheet-template.md and Spell Slot Tables.md anywhere in your Vault.
